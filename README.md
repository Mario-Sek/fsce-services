# FSCE-Services (Feature Branch Snapshot)

This repository contains a **snapshot of the feature branch** I worked on during my contributions to the [official FSCE-Services project](https://gitlab.finki.ukim.mk/wp/fcse-services) on GitLab.

---

## About

This project is a monolithic Spring Boot application using Thymeleaf and Bootstrap, developed as part of the Faculty of Computer Science and Engineering (FINKI).  
I actively contributed to the system by implementing new features, enhancing the UI, resolving bugs, and participating in merge conflict resolutions.

My contributions were part of [Task #12](https://gitlab.finki.ukim.mk/wp/fcse-services/-/issues/12), which was later merged via [Merge Request #17](https://gitlab.finki.ukim.mk/wp/fcse-services/-/merge_requests/17).

The original branch was deleted after merging, so this GitHub repository serves to **preserve the commit history and showcase my work** for portfolio and review purposes.

---

## My Key Contributions

- Built the complete **Disciplinary Decisions** feature — including services, controllers, Thymeleaf templates, and form handling
- Enhanced the **Meeting** and **Report** form behavior and validation
- Improved user interface using **Bootstrap** components
- Refactored existing code for clarity and maintainability
- Resolved multiple **merge conflicts** to integrate new features with the existing codebase
