Упатство за пополнување

Кога часовите се споделуваат помеѓу наставници:
  • Број часови = Број групи од распределба * Број часови од акредитација на предметот
  • Број на студенти = Број групи од распределба * вкупно студенти на предметот / број на групи на предметот

Кога лабораториските се консултативни:
  • Број часови = Број групи од распределба * Број часови од акредитација на предметот
  • Број на студенти = Број групи од распределба * вкупно студенти на предметот / број на групи на предметот

Кога лабораториските се изведуваат во лабораторија:
  • Број часови = Број групи неделно * 2
  • Број на студенти = Број на студенти во лабораторија (ако е сам(а) во лабораторија)
  • Број на студенти = Број на студенти во лабораторија/2 (ако се заедно со тутор или асистент во терминот)
Менторски изведувана настава:
  • Број часови = Број на часови според акредитација на предметот / 2
  • Број на студенти = Вкупен број на студенти на предметот
